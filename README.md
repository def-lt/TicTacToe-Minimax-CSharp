# Крестики-нолики с ИИ (Minimax) на C#

Консольная игра «Крестики-нолики» с искусственным интеллектом на основе алгоритма **Minimax** (с альфа-бета отсечением).

## Возможности

- ✅ Консольный интерфейс (на русском)
- ✅ Проверка победы (строки, столбцы, диагонали) и ничьей
- ✅ ИИ на алгоритме Minimax + Alpha-Beta pruning
- ✅ Три уровня сложности:
  1. **Лёгкий** — случайные ходы + слабый ИИ (глубина 2)
  2. **Средний** — Minimax с ограниченной глубиной (4) + небольшая случайность
  3. **Сложный** — полный Minimax (глубина 9) — **непобедимый**

## Запуск

Требуется [.NET 8 SDK](https://dotnet.microsoft.com/download).

```bash
dotnet run
```

Или собрать и запустить:

```bash
dotnet build
dotnet bin/Debug/net8.0/TicTacToe.dll
```

## Как играть

1. Выберите уровень сложности (1–3)
2. Вы играете **X** (крестики), ИИ — **O** (нолики)
3. Вводите ход в формате: `строка столбец` (например `2 3`)
4. Игра продолжается до победы одного из игроков или ничьей

## Структура кода

- `Program.cs` — вся логика игры
- `Minimax()` — рекурсивный алгоритм с альфа-бета отсечением
- `CheckWinner()` — проверка победы
- Уровни сложности влияют на максимальную глубину поиска и наличие случайности
